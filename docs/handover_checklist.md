# 인수인계 점검표 (P32B, 명세 19.9)

운영 담당자가 바뀔 때 넘겨주는 사람과 받는 사람이 함께 채운다. 영어판: [handover_checklist.en.md](handover_checklist.en.md).
**비밀 값(비밀번호·키·토큰·암호문구) 자체는 이 표에 적지 않는다** — "어디에 보관하는지"와 "누가 아는지"만 적는다. 채운 표는 조직의 문서 보관소에 둔다(저장소에 커밋하지 않는다).

- 표의 `[ ]`는 확인하면 `[x]`로 바꾼다. "화면에서 확인"이 있는 줄은 PJGuardian 화면이 자동으로 판정하는 값이므로 그 화면을 함께 열어 본다.
- 날짜: ________ 넘겨주는 사람: ________ 받는 사람: ________ 서버(주소·OS): ________ 앱 버전(시스템 모니터링 앱 카드): ________

## 1. 계정·시크릿·키

| 확인 | 항목 | 화면에서 확인 | 보관 위치·담당(작성) |
| --- | --- | --- | --- |
| [ ] | 로컬 관리자 계정 목록(활성 로컬 admin이 1명 이상) | 사용자 관리(`/admin/users`, 역할 admin·인증 방식 로컬) | |
| [ ] | 초기 비밀번호(`admin`)를 바꾸지 않은 관리자가 없음 | 점검 탭 하드닝·관리자 배너(`/admin/checks`) | |
| [ ] | `config/secrets.ini`(저장소 자격 증명 암호화 키)의 보관 위치·권한 | 점검 탭 보안 줄 "비밀 파일 위치·권한" | |
| [ ] | 키 파일(`.pjgkey`) 최신본과 암호문구 보관 위치(서로 다른 곳) | 백업·복원(`/admin/backups`) "키 내보내기" | |
| [ ] | 서버 OS 계정(웹 서버·워커 실행 계정, 관리자 계정) | — | |
| [ ] | LDAP 검색 계정·OIDC 클라이언트 비밀·SAML SP 키·SMTP 비밀번호를 누가 다시 넣을 수 있는지 | 설정 관리 각 탭(값은 다시 보이지 않음 — "설정됨"만) | |
