## 무엇을 하나요

로그인 화면에 나오는 안내와 오류의 뜻, 그리고 해야 할 일을 정리했습니다. 로그인 방법 자체는 [시작하기](guide:getting-started)를 보세요.

보안을 위해 PJGuardian은 로그인 실패의 자세한 이유를 화면에 보여 주지 않습니다. 이유를 알아야 하면 관리자에게 문의하세요. 관리자는 기록에서 이유를 확인할 수 있습니다.

## 아이디 또는 비밀번호가 올바르지 않을 때

다음 문구가 나옵니다.

"{{ui:error.login_failed}}"

이 문구는 없는 ID, 틀린 비밀번호, 잠긴 계정, 비활성화된 계정에서 모두 같습니다. 계정이 있는지 없는지를 드러내지 않기 위해서입니다.

1. 로그인 ID와 비밀번호를 다시 확인합니다. Caps Lock과 입력 언어(한/영)도 확인하세요.
2. 앱 계정이면 앱 비밀번호를, 조직 계정(LDAP/AD)이면 조직 비밀번호를 입력했는지 확인합니다. 앱 계정은 조직 비밀번호로 로그인되지 않습니다.
3. 계속 실패하면 더 시도하지 말고 관리자에게 문의하세요. 반복해서 실패하면 잠금이나 제한이 걸립니다.

## 계정 잠금

앱 계정은 로그인에 연속으로 실패하면 잠깁니다.

- 잠기는 연속 실패 횟수: {{limit:auth.lockout_max_failures}}
- 잠기는 시간: {{limit:auth.lockout_duration}}

잠긴 동안은 올바른 비밀번호를 넣어도 위의 일반 실패 문구가 나옵니다. 잠금 시간이 지난 뒤 다시 시도하거나, 급하면 관리자에게 잠금 해제를 요청하세요. 조직 계정(LDAP/AD)은 앱이 잠그지 않고 조직 디렉터리의 잠금 정책을 따릅니다.

## 로그인이 잠시 제한될 때

다음 문구가 나오면 같은 IP 주소에서 로그인 실패가 너무 많았던 것입니다.

"{{ui:error.too_many_attempts}}"

- 기준: {{limit:auth.ip_failure_window}} 안에 실패 {{limit:auth.ip_max_failures}}회
- 제한 시간: {{limit:auth.ip_block_duration}}

같은 사무실처럼 여러 사람이 같은 IP를 쓰면 다른 사람의 실패 때문에 제한될 수도 있습니다. 시간이 지난 뒤 다시 시도하세요. 조직 계정은 같은 로그인 ID로 실패가 반복될 때도 같은 문구로 잠시 제한됩니다.

## 임시 비밀번호가 만료됐을 때

"{{ui:error.temp_password_expired}}"

임시 비밀번호는 발급 뒤 {{limit:auth.temp_password_expiry}}이 지나면 쓸 수 없습니다. 관리자에게 새 임시 비밀번호를 요청하세요. 임시 비밀번호로 로그인하면 먼저 새 비밀번호로 바꿔야 다른 기능을 쓸 수 있습니다.

## 세션이 만료됐을 때

로그인 화면에 "{{ui:login.notice_expired}}"가 보이면 활동이 없어 자동으로 로그아웃된 것입니다.

- 활동 없이 {{limit:auth.session_idle}}이 지나면 로그아웃됩니다.
- 화면을 열어 두는 것만으로는 활동으로 치지 않습니다. 알림 개수를 확인하는 배경 요청도 활동이 아닙니다.
- 다시 로그인하면 원래 보던 화면으로 돌아갑니다. 저장하지 않은 입력은 사라질 수 있으니 오래 자리를 비우기 전에 저장하세요.

## 조직 계정 안내 상자

조직 계정(LDAP/AD·SSO)으로 로그인하면 로그인 폼 위에 안내 상자가 나올 수 있습니다. 이 안내는 조직 인증(비밀번호 확인)을 통과한 사람에게만 나옵니다. 비밀번호가 틀리면 일반 실패 문구가 나옵니다.

### 승인 대기

"{{ui:error.account_pending}}"

처음 로그인해서 계정이 만들어졌고 관리자 승인을 기다리는 중입니다. 승인 전에는 로그인되지 않습니다. 관리자에게 승인을 요청하고, 승인된 뒤 다시 로그인하세요.

### 승인되지 않음

"{{ui:error.account_rejected}}"

관리자가 계정 요청을 거절했습니다. 다시 로그인해도 바뀌지 않습니다. 관리자에게 문의하세요.

### 계정 요청을 받지 않음

"{{ui:error.account_requests_closed}}"

승인을 기다리는 계정이 너무 많아 지금은 새 계정 요청을 받을 수 없습니다. 관리자에게 문의하세요.

### 인증 서비스 문제

"{{ui:error.auth_service_unavailable}}"

PJGuardian이 조직의 디렉터리 서버에 연결하지 못했습니다. 잠시 뒤 다시 시도하고, 계속되면 관리자에게 알리세요.

## SSO 오류 코드

SSO 단추로 로그인하다 실패하면 "SSO 로그인에 실패했습니다"라는 문구와 함께 오류 코드가 나옵니다. 문구는 하나뿐이고 코드로 원인을 구분합니다. 아래에서 코드를 찾아 대처하세요. 다시 시도할 때는 주소창의 이전 주소나 즐겨찾기를 쓰지 말고, 로그인 화면에서 SSO 단추를 새로 누르세요.

### E-SSO-STATE

로그인 요청을 확인하지 못했습니다. 로그인을 시작한 뒤 시간이 오래 지났거나(10분), 같은 로그인 요청을 다시 썼거나, 시작한 브라우저와 다른 브라우저에서 끝났을 때 나옵니다.

- 같은 브라우저에서 로그인 화면을 새로 열고 SSO 단추를 다시 누르세요.
- 뒤로 가기나 새로 고침으로 조직 로그인 화면을 다시 보내지 마세요.

### E-SSO-IDP

조직의 로그인 서비스(IdP)가 오류를 돌려줬습니다. 예를 들어 조직 로그인 화면에서 동의를 거부하거나 로그인을 취소한 경우입니다.

- 다시 시도하세요.
- 계속 나오면 조직 계정에 이 앱을 쓸 권한이 있는지 관리자에게 확인하세요.

### E-SSO-TOKEN

조직 로그인 서비스가 보낸 로그인 결과를 검증하지 못했습니다.

- 한 번 다시 시도하세요.
- 계속 나오면 관리자에게 알리세요. 설정이나 인증서 문제일 수 있어 사용자가 해결할 수 없습니다.

### E-SSO-CONFIG

PJGuardian의 SSO 설정에 문제가 있습니다. 다시 시도해도 해결되지 않습니다. 관리자에게 알리세요.

### E-SSO-UNAVAILABLE

조직 로그인 서비스에 연결하지 못했거나 응답이 너무 늦었습니다. 잠시 뒤 다시 시도하고, 계속되면 관리자에게 알리세요.

### E-SSO-RATE

짧은 시간에 로그인 요청이 너무 많았거나, 로그인 실패가 많아 접속한 곳의 IP가 잠시 제한됐습니다. 잠시 기다린 뒤 다시 시도하세요.

### E-SSO-DENIED

조직 인증은 통과했지만 PJGuardian 계정을 정할 수 없어 거부했습니다. 같은 로그인 ID의 다른 계정이 이미 있거나, 계정이 비활성화됐거나, 조직이 보낸 로그인 ID를 쓸 수 없는 경우입니다. 다시 시도해도 바뀌지 않으니 관리자에게 문의하세요.

## 관리자에게 알릴 것

관리자에게 문의할 때 다음을 알려 주면 빨리 확인할 수 있습니다.

- 화면에 나온 문구 또는 오류 코드(예: E-SSO-TOKEN)
- 로그인을 시도한 시각
- 쓴 로그인 방법(ID·비밀번호, SSO 단추 이름)과 로그인 ID

비밀번호는 관리자에게도 알려 주지 마세요. 자세한 내용은 [오류 메시지 해결](guide:errors-help)을 보세요.
