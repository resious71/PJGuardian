## 무엇을 하나요

화면에 보이는 목록을 파일로 내려받습니다. 형식은 Excel(.xlsx)과 CSV 두 가지입니다. PDF 내보내기는 없습니다.

내보낼 수 있는 목록은 다음 세 가지입니다.

- 프로젝트의 "{{ui:defects.tab}}" 탭 결함 목록
- {{icon:nav.my_defects}} 목록(볼 수 있는 프로젝트의 결함만)
- {{icon:nav.rules}} 목록(지금 고른 언어 탭의 규칙만)

## 내보내기 단계

1. 목록 화면에서 필터나 검색 조건을 정하고 검색 단추를 눌러 적용합니다.
2. 표 바로 위 오른쪽의 {{ui:export.xlsx}} 또는 {{ui:export.csv}} 단추를 누릅니다.
3. 파일이 만들어지면 브라우저가 내려받습니다. 끝나면 내보낸 건수가 안내됩니다.

파일을 만드는 동안에는 두 단추가 꺼져 있습니다. 여러 번 눌러도 요청은 하나만 갑니다.

## 무엇이 내보내지나요

- **마지막으로 검색한 조건**의 결과 전체가 내보내집니다. 지금 보이는 쪽만이 아니라 조건에 맞는 모든 행이 들어갑니다. 정렬도 화면과 같습니다.
- 검색 영역에서 조건을 바꾸고 아직 검색하지 않았다면 바뀐 조건은 쓰지 않습니다. 이때 단추 옆에 "{{ui:export.applied_note}}" 안내가 나옵니다. 바뀐 조건으로 내보내려면 먼저 검색하세요.
- **과거 Run**을 보고 있으면 "Run N 기준"으로 그 Run 시점의 값을 내보내고, 파일 이름에도 Run 번호가 붙습니다([히스토리](guide:history)).
- 결함 파일의 열: 결함 번호, 도구, 규칙, 심각도, 상태, 담당자, 파일, 줄, 메시지, 최근 감지 Run, 최근 감지 일시, 처음 감지 Run. 내 결함 파일은 맨 앞에 프로젝트 열이 더 있습니다.
- 규칙 파일의 열: 도구, 규칙 키, 이름, 카테고리, 기본 심각도, 분석 적용, 관리자 변경, 기본 활성, 자동 수정, 폐기 예정, 요약, 기준 도구 버전, 공식 문서, 버전 변경.
- 열 이름과 상태·심각도 같은 값은 지금 화면 언어로 씁니다. 결함 메시지와 규칙 설명은 도구 원문 그대로입니다.
- 파일 이름에는 프로젝트 이름과 내보낸 시각이 들어갑니다.

## Excel과 CSV의 차이

- **Excel(.xlsx)**: 첫 시트에 목록이 있고, 머리글 행이 고정되고 자동 필터가 걸려 있습니다. 둘째 시트 "{{ui:export.sheet.info}}"에는 내보낸 시각, 프로젝트, 적용된 조건, 정렬, 보기 Run, 행 수가 적혀 있습니다. 내보낸 사람의 정보는 넣지 않습니다.
- **CSV**: UTF-8(BOM 포함), 쉼표로 구분한 파일입니다. Excel에서 열어도 한글이 깨지지 않습니다. 다른 프로그램에서 데이터를 처리할 때 편합니다.

## 수식 문자 보호

내보낸 파일을 스프레드시트에서 열 때 셀 값이 수식으로 실행되지 않도록 막습니다.

- CSV에서는 `=`, `+`, `-`, `@`, 탭, 줄바꿈으로 시작하는 값 앞에 작은따옴표(`'`)를 붙입니다. 그래서 이런 값은 맨 앞에 `'`가 보일 수 있습니다.
- Excel 파일은 모든 글자를 텍스트 셀로만 쓰고 수식 셀을 만들지 않습니다.
- 한 셀은 32,767자까지만 들어가며, 넘으면 잘리고 끝에 "{{ui:export.truncated}}" 표시가 붙습니다.

## 한도와 오류

- 한 번에 내보낼 수 있는 행 수: {{limit:export.max_rows}}
- 결과가 이보다 많으면 파일을 만들지 않고 건수와 상한을 알려 줍니다. 잘라서 일부만 주지 않습니다. 조건을 좁혀 여러 번 나눠 내보내세요.
- 결과가 0건이면 단추가 꺼져 있습니다(마우스를 올리면 이유가 보입니다).
- "{{ui:export.busy_error}}"가 나오면 진행 중인 내보내기가 끝난 뒤 다시 누르세요. 한 사람이 동시에 여러 파일을 만들 수 없고, 서버 전체의 동시 내보내기 수에도 한도가 있습니다.
- 시간 안에 끝나지 않으면 중단됩니다. 조건을 좁혀 다시 시도하세요.

그 밖의 오류는 [오류 메시지 해결](guide:errors-help)을 보세요.

## 주의

- 내보낸 파일에는 프로젝트의 코드 위치와 메시지가 들어 있습니다. 공유할 때 조직의 정보 보안 규칙을 지키세요.
- 상세가 삭제된 Run을 보고 있을 때는 내보내기 단추가 나오지 않습니다. 최신 Run으로 돌아가 내보내세요.
