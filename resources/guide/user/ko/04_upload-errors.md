## 오류가 보이는 곳

업로드가 실패하면 업로드 화면에 오류 제목과 설명, 그리고 "조치: … (오류 코드 …)" 줄이 나옵니다. 문제가 된 항목이 있으면 ZIP 안의 항목 이름도 함께 보입니다.

모든 오류 코드의 원인과 조치는 [오류 코드](/guide/errors) 탭에 한 줄씩 정리되어 있습니다. 여기서는 원인별로 묶어 해결 방법을 설명합니다.

실패한 업로드는 이어 올릴 수 없습니다. 원인을 고친 뒤 처음부터 다시 올리세요.

## ZIP 파일 자체의 문제

- `invalid_zip`(유효하지 않은 zip): ZIP 형식이 아니거나, 파일이 중간에 잘렸거나, 같은 이름의 항목이 중복되었거나, 암호가 걸린 항목이 있습니다.

할 수 있는 일:

1. 압축 프로그램으로 ZIP을 다시 만드세요. 암호는 걸지 마세요.
2. 또는 {{ui:upload.pick_folder}}로 폴더를 직접 고르세요. 브라우저가 알맞은 형식으로 묶어 줍니다.

## 크기와 파일 수 한도

- `zip_too_large`(업로드 용량 초과): 올린 파일이 업로드 한도({{limit:upload.max_zip_size}})를 넘습니다.
- `extract_limit`(해제 후 총량·파일 수 초과): 압축을 푼 크기({{limit:extract.max_extracted_size}}) 또는 파일 수({{limit:extract.max_files}}) 한도를 넘습니다.
- `extract_timeout`(압축 해제 시간 초과): 파일이 아주 많아 제한 시간 안에 압축을 풀지 못했습니다.

할 수 있는 일:

1. 분석에 필요 없는 파일을 빼고 다시 묶으세요. 빌드 결과, 의존성 폴더, 데이터 파일, 생성된 파일이 흔한 원인입니다.
2. 폴더로 올릴 때는 "{{ui:upload.skip_excluded}}"를 켜 두세요.
3. 계속 반복해서 빼야 하는 폴더가 있으면 관리자에게 프로젝트 제외 패턴 추가를 요청하세요.

## 허용하지 않는 항목

- `forbidden_entry`(금지 항목 포함): 경로 조작(`..`), 절대 경로, 역슬래시(`\`)를 쓴 경로, 심볼릭 링크, ZIP 안의 ZIP(`.zip` 파일) 같은 항목이 있습니다.

할 수 있는 일:

1. 오류에 표시된 항목 이름을 확인하세요.
2. 그 항목을 빼거나, 링크는 실제 파일로 바꿔 다시 묶으세요.
3. ZIP 안에 들어 있는 `.zip` 파일은 빼고 올리세요.
4. 경로 구분자로 역슬래시를 쓰는 압축 프로그램에서 생긴 문제라면 다른 압축 프로그램을 쓰거나 폴더를 직접 고르세요.

경로 조작, 절대 경로, 역슬래시는 제외 대상 안에 있어도 거부됩니다. 심볼릭 링크와 ZIP 안의 ZIP은 제외 대상 밖에 있을 때만 문제가 됩니다.

## 파일 이름 문제

- `filename_encoding`(파일 이름 인코딩): ZIP 안의 파일 이름을 UTF-8이나 CP949로 읽을 수 없습니다.
- `unsupported_name`(사용할 수 없는 파일 이름): Windows에서 쓸 수 없는 이름(`CON` 같은 예약 이름, 금지 문자, 끝의 점·공백)이나 너무 긴 경로가 있습니다.
- `name_conflict`(이름 충돌): 대소문자나 유니코드 정규화만 다른 같은 이름의 파일, 또는 같은 이름의 파일과 폴더가 있습니다.

할 수 있는 일:

1. `filename_encoding`: UTF-8 파일 이름을 지원하는 압축 프로그램으로 다시 묶거나 폴더를 직접 고르세요.
2. `unsupported_name`: 표시된 파일의 이름을 바꾸거나 폴더 깊이를 줄여 경로를 짧게 하세요.
3. `name_conflict`: 둘 중 하나의 이름을 바꾸세요. 예를 들어 `Readme.md`와 `README.md`는 함께 둘 수 없습니다.

Windows 이름 규칙은 제외 대상 밖의 항목에만 적용됩니다.

## 서버 처리 중 문제

- `assemble_failed`(조립 실패): 받은 조각을 하나로 합치지 못했거나, 합친 결과의 크기·해시가 맞지 않습니다.
- `io_error`(서버 파일 쓰기 오류): 압축을 푸는 중 서버가 파일을 쓰지 못했습니다.
- `extract_crashed`(압축 해제 작업 중단): 압축을 푸는 작업이 비정상 종료되었습니다.

할 수 있는 일:

1. 잠시 뒤 처음부터 다시 올리세요.
2. 같은 오류가 계속되면 오류 코드와 업로드 시각을 관리자에게 알려 주세요.

## 업로드를 시작하지 못할 때

전송을 시작하기 전에 거부되는 경우도 있습니다. 이때는 화면에 안내 문구만 보입니다.

- 동시에 진행할 수 있는 업로드 수({{limit:upload.max_concurrent_per_user}})를 넘었습니다: 진행 중인 업로드가 끝나거나 취소한 뒤 다시 시도하세요.
- 업로드 용량 한도를 넘었습니다: 불필요한 파일을 빼고 다시 묶으세요.
- 서버 저장 공간이 부족하거나 디스크 사용률이 높습니다: 관리자에게 문의하세요.
